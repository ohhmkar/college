## Course Objectives

To develop skills in designing and implementing fundamental data structures. The course focuses on:

- Linear structures: arrays, linked lists, stacks, queues
- Non-linear structures: trees, graphs
- Searching and sorting algorithms
- Algorithm analysis and complexity

## Learning Outcomes

After completing this course you will be able to:

1. Implement and apply linear and non-linear data structures
2. Analyse the time and space complexity of algorithms
3. Choose appropriate data structures for a given problem
4. Implement graph and tree algorithms
