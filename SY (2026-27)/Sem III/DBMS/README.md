## Course Objectives

To develop skills in designing and querying relational databases. The course focuses on:

- Relational model, ER diagrams, normalization
- SQL — DDL, DML, DCL, TCL
- Transactions, concurrency control, recovery
- Indexing and query optimization

## Learning Outcomes

After completing this course you will be able to:

1. Design a normalized relational database schema from requirements
2. Write complex SQL queries including joins, subqueries, and aggregations
3. Explain transaction management and concurrency control mechanisms
4. Apply indexing strategies to optimize query performance
