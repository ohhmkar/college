## Course Objectives

To develop mathematical foundations for computer science. The course focuses on:

- Logic, sets, relations, and functions
- Combinatorics and counting techniques
- Graph theory: representations, traversals, shortest paths
- Trees, spanning trees, and applications

## Learning Outcomes

After completing this course you will be able to:

1. Apply logic and set theory to formalize problems
2. Use combinatorics to analyse algorithms
3. Model problems using graphs and apply standard graph algorithms
4. Prove correctness of algorithms using mathematical reasoning
