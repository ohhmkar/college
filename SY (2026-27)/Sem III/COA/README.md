## Course Objectives

To understand the design and operation of computer systems. The course focuses on:

- Digital logic, number systems, and data representation
- Processor design: ALU, control unit, instruction sets
- Memory hierarchy: cache, RAM, virtual memory
- I/O systems and interrupts

## Learning Outcomes

After completing this course you will be able to:

1. Explain the organization and architecture of a computer system
2. Design basic digital circuits and understand processor internals
3. Describe memory hierarchy and its impact on performance
4. Understand instruction-level parallelism and pipelining
