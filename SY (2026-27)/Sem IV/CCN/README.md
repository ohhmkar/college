## Course Objectives

To understand the principles of computer networking. The course focuses on:

- Network models: OSI and TCP/IP layers
- Data link layer: framing, error control, MAC protocols
- Network layer: IP addressing, routing algorithms
- Transport layer: TCP, UDP, congestion control
- Application layer: DNS, HTTP, SMTP

## Learning Outcomes

After completing this course you will be able to:

1. Explain the functions of each layer in the TCP/IP model
2. Configure and troubleshoot basic network setups
3. Analyse routing and switching protocols
4. Describe transport-layer mechanisms for reliable communication
