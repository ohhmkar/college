## Course Objectives

To understand the principles and design of operating systems. The course focuses on:

- Process management: scheduling, synchronization, deadlocks
- Memory management: paging, segmentation, virtual memory
- File systems and I/O management
- OS security and protection

## Learning Outcomes

After completing this course you will be able to:

1. Explain process scheduling and synchronization mechanisms
2. Describe memory management strategies and virtual memory
3. Design and implement basic OS components
4. Analyse OS security and protection mechanisms
