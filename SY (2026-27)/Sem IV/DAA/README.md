## Course Objectives

To develop skills in designing efficient algorithms and analysing their complexity. The course focuses on:

- Asymptotic analysis: Big-O, Θ, Ω notations
- Algorithm design paradigms: divide & conquer, greedy, dynamic programming, backtracking
- Graph algorithms: MST, shortest paths, network flow
- NP-completeness and approximation algorithms

## Learning Outcomes

After completing this course you will be able to:

1. Analyse the time and space complexity of algorithms
2. Apply standard algorithm design paradigms to solve problems
3. Implement and compare graph algorithms
4. Classify problems by computational complexity
