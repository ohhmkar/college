File Extensions: 

1. .java

.java file store the code, these are human readable text files containing the Java programming language. The class name defined within the class must match the filename. Ex. Class HelloWorld must be in a file HelloWorld.java

2. .class 

.class files are produced on compilation of a java program. The .javac command converts the code into bytecode and that bytecode is stored in the .class file. The JVM then executes the bytecode.
This file is imperative to the claim of JAVA being run anywhere programming language as it compiles into bytecode and can be interpreted by any machine as long as it has a supported JVM.

3. .ctxt

.ctxt files are files generated by BLUEJ on compilation, storing meta information about the JAVA class, like documentation, comments and position in the class diagram. One .ctxt file accompanies each .java class file, and they are generally not needed for the program to run outside the BLUEJ env. 
These files are useful as they generate auto documentation.
