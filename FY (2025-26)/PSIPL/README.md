## Course Objectives

To develop problem-solving skills using imperative programming paradigms (C language). The course focuses on:

- Problem analysis and algorithm design
- Implementation using control structures, arrays, text processing
- Modular program design using functions and structures

## Learning Outcomes

After completing this course you will be able to:

1. Explain problem-solving aspects using imperative programming paradigms.
2. Solve real-world problems by designing algorithms and implementing them in C.
3. Apply control structures (loops, conditionals) to implement solutions.
4. Work with arrays and strings for data processing tasks.
5. Design modular programs using functions and user-defined types.
6. Use structures and unions to model complex data.
