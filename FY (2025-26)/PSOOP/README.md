## Course Objectives

To develop problem-solving skills using object oriented programming paradigms (Java language). The course focuses on:

- Problem analysis and algorithm design
- Implementation using control structures, arrays, text processing
- Apply OOP design principles — encapsulation, inheritance, polymorphism, abstraction

## Learning Outcomes

After completing this course you will be able to:

1. Apply concepts of object oriented programming using classes and objects
2. Apply Inheritance for a given scenario
3. Apply polymorphism for solving a given problem
4. Apply abstraction and exception handling to create efficient programs.
